> ⚠️ **Важно про авторские права.** GTA VI / Grand Theft Auto VI — это торговая марка и
> объект авторского права Rockstar Games. Скачивать, копировать или воспроизводить её код,
> модели, текстуры, карту, персонажей или аудио **юридически невозможно** — даже «полная копия»
> была бы пиратством. Поэтому здесь сделана честно: **ориджинальная игра в жанре**
> (open-world песочня с городом, машинами, пешеходами, полицией и миссиями),
> вдохновлённая эстетикой неонового прибрежного мегаполиса, со **100% собственными
> процедурными ассетами**. Ни один байт оригинала GTA VI не скачивался и не использовался.

## Что внутри

| Система | Файл | Описание |
|---|---|---|
| Рендер + игровой цикл | `js/main.js` | Three.js r128 (vendored, работает офлайн), динамическое качество |
| Адаптивное качество | `js/config.js` | Пресеты LOW/MEDIUM/HIGH + авто-FPS-масштабирование для слабых телефонов |
| Город | `js/world/buildings.js` | ~150 зданий через InstancedMesh (6 draw calls), canvas-фасады со светящимися окнами |
| Улицы | `js/world/roads.js` | Сетка улиц, тротуары, разметка |
| Природа | `js/world/nature.js` | Пальмы (instancing), пляж, анимированный океан |
| День/ночь | `js/world/lighting.js` | Солнце, туман, градиентное небо, закат, ночные фонари |
| Игрок | `js/entities/player.js` | Ходьба/бег/прыжок, коллизии, посадка в авто |
| Люди | `js/entities/ped.js`, `npc.js` | Процедурные low-poly модели, анимация шага, NPC с LOD и паникой |
| Машины | `js/entities/vehicle.js` | Аркадная физика, вращение колёс, угон |
| Трафик | `js/systems/traffic.js` | AI-машины ездят по перекрёсткам, респавн вне зоны видимости |
| Полиция | `js/systems/wanted.js` | Звёзды розыска 1–6, преследование, арест со штрафом |
| Миссии | `js/systems/missions.js` | Цепочка: маркер → угон → гонка по чекпоинтам → пляж |
| HUD | `js/ui/hud.js` | Деньги, звёзды, спидометр, полоса здоровья, **живая миникарта** |
| Управление | `js/systems/input.js` | WASD/стрелки/E/F/Space + сенсорный джойстик и кнопки |

## Оптимизация под слабые устройства
- **InstancedMesh** вместо сотен отдельных мешей (весь город ≈ 10 вызовов отрисовки).
- **Динамический renderScale**: FPS < 32 → автоматическое понижение качества на ходу.
- **LOD симуляции**: NPC и трафик считаются только в радиусе ~55–60 м, дальше — телепорт-респавн.
- **Коллизии через spatial hash**, а не перебор всех боксов.
- Миникарта перерисовывается 15 раз/сек вместо 60; текстур нет вообще — всё рисуется на canvas 128px.
- Кадронезависимая физика (`damp`), dt-кламп против «прыжков времени».

## Как запустить
```bash
cd gta6-mobile
python3 -m http.server 8777
# открыть http://localhost:8777/index.html
```
Можно и просто открыть `index.html` файлом — three.js лежит в `vendor/`, интернет не нужен.

## Управление
- **ПК**: WASD/стрелки — идти, Shift — бежать, Space — прыжок, E/F — сесть/выйти из машины,
  ЛКМ-драг — камера, C — режим камеры (follow/first/cinematic), K — «нарушение» для теста розыска.
- **Телефон**: виртуальный джойстик слева, свайп справа — камера, кнопки ⤴/⏎/👁.
